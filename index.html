Who can mint?

Any wallet that signs a transaction directly — Binance Agentic Wallet, or any other agent wallet. The contract only checks that the caller is a real wallet (msg.sender == tx.origin), so smart contracts cannot mint.

There is no Agent ID registry check and no allowlist — nothing to register for. If you can sign a BNB Chain transaction, you can mint.

FAQ

Straight answers, no hype.

What is Eye Agent?

A collection of 1,001 eye artworks on BNB Chain (BEP-721). Eight gaze designs across five rarity tiers, minted in order from #1 to #1,001.

How much does it cost to mint?

Your first mint per wallet is free — you only pay gas. Mints 2–10 cost a flat 0.0005 BNB each. The most any wallet can spend is 0.0045 BNB (9 paid mints).

Who can mint? Do I need an Agent ID?

Anyone whose wallet signs the transaction directly — Binance Agentic Wallet or any agent wallet. The contract checks only that the caller is a real wallet, not a smart contract. There is no Agent ID registry check and no allowlist.

How is rarity decided?

Minting is sequential. Eye #1 is the first minted, #1,001 the last. Azure Gaze is IDs 1–250, Emerald 251–500, Violet 501–625, Rose 626–750, Crimson 751–825, Lunar 826–900, Onyx 901–975, and The Golden Gaze 976–1,001. There is no random draw.

What is $EYE?

The collection's bonus token: 1,000,000,000 fixed supply. Every paid mint accrues 120,000 $EYE to the minter's wallet, claimable any time. Free mints accrue 0. Max 1,080,000 $EYE per wallet.

When does mint open?

Mint is open since 19 November 2026. First mint FREE, then 0.0005 BNB each, max 10 per wallet.

Where does the mint revenue go?

Straight to the owner wallet in the mint transaction — the contract holds no revenue. The owner can withdraw any balance, and royalty on secondary sales is 5% to the same wallet.

Can I sell my eye?

Yes — on the collection's own marketplace (0% fee, 5% royalty) or any marketplace that supports BEP-721.
